# 稅籍異動即時通－守護房產大作戰

臺北市稅捐稽徵處為民服務宣導互動式網頁小遊戲。

## 遊戲介紹
透過活潑有趣的闖關問答，認識「稅籍異動即時通」服務：申請方式、通知內容、通知管道與服務功能。

- 共 5 道題目，每題 20 分，滿分 100 分
- 支援手機、平板與電腦
- 純前端製作，無蒐集任何個人資料

## 線上遊玩
啟用 GitHub Pages 後，可於以下網址遊玩：

**https://ct-2486.github.io/tax-notification-game/**

## 本機開啟
直接下載 `index.html` 用瀏覽器開啟即可。
