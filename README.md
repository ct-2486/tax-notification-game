# 稅籍＋地籍異動即時通－守護房產大作戰

互動式網頁教育遊戲，全面結合「稅籍異動即時通」與「地籍異動即時通」雙重守護觀念。

## 遊戲特色
- **雙重主軸**：5 道題目完整涵蓋稅籍與地籍兩項服務
- 認識服務本質、通知內容、申請管道與雙重守護觀念
- 每題 20 分，滿分 100 分，挑戰成為「雙重守護達人」
- 支援手機、平板與電腦，純前端、無蒐集個人資料

## 線上遊玩
**https://ct-2486.github.io/tax-notification-game/**

（請先在倉庫 Settings → Pages 啟用 Deploy from branch: main / root）

## 本機開啟
下載 `index.html` 用瀏覽器直接開啟即可。

## 官方服務資訊

### 稅籍異動即時通
- [臺北市稅捐稽徵處－服務說明](https://tpctax.gov.taipei/cp.aspx?Create=1&ccms_cs=1&n=3751069E7801B73E&s=55C50D260B8ED960&state=F5D336F102ACBC68)
- 線上申請：[地方稅網路申報作業](https://net.tax.nat.gov.tw)

### 地籍異動即時通
- 線上申請：[內政部數位櫃臺](https://dcland.moi.gov.tw/)
- 亦可至全國任一地政事務所臨櫃申請
