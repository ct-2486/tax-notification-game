# 稅籍異動即時通－守護房產大作戰

臺北市稅捐稽徵處為民服務宣導互動式網頁小遊戲，並一併宣導**地籍異動即時通**，雙重守護房產權益。

## 遊戲介紹
透過活潑有趣的闖關問答，認識「稅籍異動即時通」服務：申請方式、通知內容、通知管道與服務功能。
同時於遊戲中介紹「地籍異動即時通」，建議民眾兩項服務都申請。

- 共 5 道題目，每題 20 分，滿分 100 分
- 支援手機、平板與電腦
- 純前端製作，無蒐集任何個人資料

## 線上遊玩
啟用 GitHub Pages 後，可於以下網址遊玩：

**https://ct-2486.github.io/tax-notification-game/**

## 本機開啟
直接下載 `index.html` 用瀏覽器開啟即可。

## 官方服務資訊

### 稅籍異動即時通
- [臺北市稅捐稽徵處－服務說明](https://tpctax.gov.taipei/cp.aspx?Create=1&ccms_cs=1&n=3751069E7801B73E&s=55C50D260B8ED960&state=F5D336F102ACBC68)
- 線上申請：[地方稅網路申報作業](https://net.tax.nat.gov.tw)

### 地籍異動即時通
- 線上申請：[內政部數位櫃臺](https://dcland.moi.gov.tw/)
- 亦可至全國任一地政事務所臨櫃申請
